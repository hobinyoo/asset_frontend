# 문서 동기화

현재 코드 상태와 문서가 일치하는지 확인합니다.

## 지침

1. **최근 코드 변경 사항 찾기**:
   ```bash
   git log --since="30 days ago" --name-only --pretty=format: -- "*.ts" "*.tsx" | sort -u
   ```

2. **관련 문서 찾기**:
   - `/docs/`에서 변경된 코드를 언급하는 파일 검색
   - 변경된 코드 근처의 README 파일 확인
   - 변경된 파일의 TSDoc 주석 확인

3. **문서 정확성 검증**:
   - 코드 예시가 여전히 작동하는가?
   - API 시그니처가 올바른가?
   - Prop 타입이 최신 상태인가?

4. **실제 문제만 보고**:
   - 문서는 살아있는 문서
   - 잘못된 것만 플래그, 누락된 것은 제외
   - 문서를 위한 문서 제안 금지

5. **업데이트가 필요한 문서 체크리스트 출력**
