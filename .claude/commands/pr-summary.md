# PR 요약

현재 브랜치의 풀 리퀘스트 요약을 생성합니다.

## 지침

1. **변경 사항 분석**:
   ```bash
   git log main..HEAD --oneline
   git diff main...HEAD --stat
   ```

2. **다음 내용을 포함한 요약 생성**:
   - 변경된 내용에 대한 간략한 설명
   - 수정된 파일 목록
   - 브레이킹 변경 사항 (있는 경우)
   - 테스트 참고 사항

3. **PR 본문 형식으로 작성**:
   ```markdown
   ## 요약
   [변경 사항을 설명하는 1-3개의 불릿 포인트]

   ## 변경 사항
   - [주요 변경 사항 목록]

   ## 테스트 계획
   - [ ] [테스트 체크리스트 항목]
   ```
